# Phone_Bridge
**PhoneBridge** is a lightweight alternative to Microsoft Phone Link, designed to connect your Android device to your Windows PC. It provides a simple and convenient way to bridge your phone and computer, with essential features, a minimal interface, and low resource usage.  **Stay connected. Keep it simple.** 🚀

**PhoneBridge** یک جایگزین سبک و کم‌حجم برای Microsoft Phone Link است که با هدف اتصال گوشی‌های اندرویدی به کامپیوترهای ویندوزی طراحی شده است. این برنامه راهی ساده و کاربردی برای ارتباط بین گوشی و کامپیوتر فراهم می‌کند و با رابط کاربری مینیمال و مصرف منابع پایین، تجربه‌ای روان و آسان ارائه می‌دهد.

**همیشه متصل؛ ساده و سریع.** 🚀
